# 🦴 Osteoporosis Risk Prediction

![Python](https://img.shields.io/badge/Python-3.8+-blue.svg)
![Healthcare](https://img.shields.io/badge/Healthcare-Prediction-orange.svg)

## 📖 Overview

Machine learning model to predict osteoporosis risk using patient demographics, lifestyle factors, and medical history. Identifies high-risk individuals for early intervention.

## 🎯 Features

- Risk stratification
- Feature importance analysis
- Preventive care recommendations
- Multi-model comparison

## 🛠️ Tech Stack

- Scikit-learn, XGBoost, LightGBM
- Pandas, NumPy
- Matplotlib, Seaborn

## 🚀 Quick Start

```bash
git clone https://github.com/adityavdn/Osteoporosis-Risk-Prediction.git
pip install -r requirements.txt
jupyter notebook
```

## 📊 Risk Factors

- Age, Gender, BMI
- Calcium/Vitamin D intake
- Physical activity
- Family history
